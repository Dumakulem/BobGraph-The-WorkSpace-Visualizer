# Open the Visualizer

Click below to open the graph panel. You can also run **BOB AI: Open Workspace Visualizer**
from the Command Palette at any time - it is the only command this extension registers.

[Open Workspace Visualizer](command:bobai-visualizer.openVisualizer)

The panel opens beside your editor and loads the workspace graph automatically. If nothing
appears, open the webview developer tools with
**Developer: Open Webview Developer Tools** and check the console - load failures are
reported there rather than as a notification.

> Currently this renders bundled sample data. Live Bob 2.0 output is the next milestone.
