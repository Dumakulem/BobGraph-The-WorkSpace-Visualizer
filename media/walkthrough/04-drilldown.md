# Drill into a File

**Double-click** any file node in the workspace graph to open that file's flowchart. The view switches to a top-to-bottom `dagre` layout showing the logic steps inside that single file.

A breadcrumb appears above the canvas:

```
Workspace › todo-app.js
```

Click **← Back to Workspace** to return to the overview, or hit **Refresh Graph** to re-run the flowchart layout if nodes look cramped.

If a file has no flowchart data, the panel stays on the workspace view and shows the reason in the details panel — you are never left on a half-loaded screen.
