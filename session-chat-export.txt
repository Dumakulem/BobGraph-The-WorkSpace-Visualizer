USER: Will it be able to create the JSON for the webview?

ASSISTANT:
Yes, the intended pipeline is:

IBM Bob
  -> analyze workspace
  -> return structured graph data
  -> writeGraph()
  -> .bobgraph/workspace-graph.json
  -> readGraph()
  -> postMessage({ type: 'graphData', graph })
  -> webview renders graph

Canonical graph shape:

{
  "nodes": [
    {
      "id": "src/extension.ts",
      "label": "extension.ts",
      "type": "file",
      "filePath": "src/extension.ts"
    }
  ],
  "edges": [
    {
      "from": "src/extension.ts",
      "to": "src/panel/graphPanel.ts",
      "relation": "imports"
    }
  ]
}

The existing graphStore.ts already validates and writes this format. The webview
does not need to know how Bob generated the data.

      "type": "string",

    }
  ],
  "edges": [
    {
      "from": "string",
      "to": "string",
      "relation": "string"
    }
  ]
}

Rules:
1. Create one node per relevant source file.
2. IDs should be normalized workspace-relative paths.
3. filePath must be relative to the workspace root.
4. Do not use absolute paths or "..".
5. Every edge endpoint must match an existing node ID.
6. Do not invent files.
7. Return the complete graph.
